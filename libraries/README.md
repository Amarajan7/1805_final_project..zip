This project was created with my classmate AMy, it was a collaborative project and our main idea was to explore the theme of nostalgia. We wanted to show the difference between the older technology we grew up with and the technology used in modern days. Thats why we used the Nintendo DS as the good object and the phone as the Bad one in our game. The DS represents fun from the past and the phone shows that modern day technology is consuming.

We also tried to demonstrate this idea through the visuals, we used a glitchy and retro style for the designs in our game like our character sprite, the DS, the phone and the backgrounds. The pixelated visuals helped us connect more with the theme we were exploring when creating this game. We alsu used tilemaps for some fo the stages which helped hilight the retro theme as it made the character moved in blocks.

One of our biggest challenges was communication. I was away for about a month and a half during the project, so we had to work together online instead of person which limited what we could do together in that time. It was harder to run rests and fix erros. To deal with this, we decided to split the work into sections so we could each make progress.

At the start, i worked on creating the backgrounds and visuals while amy focused on game ideas and mechanics. After that we swapped rolls so we could both experiment with different parts of the projects. I started with coding some of the stages while amy worked on creating the character sprites and the DS and phone design.

We both found it was a case of alot of trial and error when coding, we found that amys code for the first stage ran better than mine and my code for the second stage worked better with our game. Instea dof choosing one over the other we combined our code to make the game stronger overall.

For the final stage we were able to work together in person, which made a big difference. It was alot easier to share ideas and fix problems when we were both in the same place. We worked together to create the third stage, which is based of a p5.js snake tutorial we found on youtube. We then changed it abit to fit our game by adding falling phones as obstacles and using the DS as the object the player collects.

Overall, this project helped us learn alot about communication and teamwork. Even though working online was a challange at times, we werw able to organise ourselves and complete the game successfully and also improve our communication skills when it comes to working on joint projects. We managed to make everything run smoothly enough in the end. If i were to do this project again id make sure we had a better idea of how we could communicate beforehand so we didnt have to figure it out as we went along, I think we both collaborated well on this project and split and worked on the project fairly together to create a nostalgic themed mini game.
